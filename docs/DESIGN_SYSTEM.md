# Waylo Design System Inventory

Source of truth: the five approved desktop/mobile concepts generated for this Build Week task.

## Visual character and tokens

Calm academic navigation with deep-ink structural chrome, warm-ivory work surfaces, navy text, restrained blue actions, thin borders, limited shadows, and generous whitespace. The roadmap is the centerpiece; this is not a chatbot, a dark AI startup, or a KPI dashboard.

- Work surface `#FFFDF7`; structural ink `#10243E`; navy `#0B2545`; muted `#52647A`; border `#D7DEE8`
- Primary `#155EEF`; Cognitive Science `#6941C6`; Data Science `#0E9384`
- Confirmed `#15803D`; warning `#D97706`; blocker `#D92D20`
- Radii: 8px controls, 12px panels, 16px major surfaces; restrained elevation
- Locally bundled Geist Sans and Geist Mono; 14-16px body, 12-13px metadata, 28-36px desktop titles, 26-32px mobile titles

## Components and interactions

App shell, responsive navigation, Academic Twin position strip, dependency route canvas, mobile route narrative, semantic zoom, Time Machine tabs, contextual review rail, command preview, outcome ledger, evidence drawer, uncertainty action card, extraction review table, planning trace, Judge Mode sheet, requirement-change detector, advisor decision packet, buttons, selects, toggles, dialogs, sheets, and print section.

Core interactions: review an uncertain transcript course; inspect route dependencies; use a natural-language detour; preview structured constraints; compare baseline/proposed/repaired states; acknowledge a missed target; confirm a validated route; upload and review evidence; inspect source/validation operations; compare controlled requirement versions; open Judge Mode; print a decision packet; reset data.

## Responsive behavior

Desktop uses a fixed sidebar, a wide focusable SVG dependency canvas, semantic route focus, and contextual right rail. Mobile replaces the canvas with a vertical dependency narrative, expandable details, and reachable confirmation actions. Editable tables stack without page overflow.
