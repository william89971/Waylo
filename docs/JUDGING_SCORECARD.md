# Waylo Judging Scorecard

Updated: 2026-07-13 — Phase 0

| Criterion | Target evidence | Current state |
| --- | --- | --- |
| Technological implementation | Deterministic graph/scheduler/validator, typed simulation, GPT-5.6 tool boundary, meaningful tests | Architecture locked; implementation pending |

Strengths: narrow audience, high-consequence demo, deterministic correctness boundary, visible evidence/uncertainty, three-day buffer.

Risks requiring proof: articulation coverage, non-scripted Calculus simulation, live model execution, route diversity, and visual fidelity.

No criterion is complete from documentation alone. Final claims must link to a working screen, test, browser evidence, or evaluation result.
